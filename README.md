# Licences

Les logiciels payés par l'entreprise et utilisés par personne.

- `PLAN.md` : plan de build, décisions, journal.
- `lib/entreprise.ts` : informations légales affichées sur le site.
- `lib/offre.ts` : formules, prix et garantie.
- `.env.example` : variables à régler dans Vercel.

```bash
npm install
npm run dev
```
